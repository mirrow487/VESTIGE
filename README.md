# VESTIGE

A Minecraft RPG overhaul mod for **Minecraft Java 1.21.1 · NeoForge 21.1.266 · Java 21**.

Reclaim a dying world one boss at a time: Terraria-style progression, Elden Ring-style combat, inside Minecraft's sandbox.
